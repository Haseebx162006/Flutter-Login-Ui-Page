# 📱 Flutter Login Screen UI

A modern, minimal, and responsive **login screen** built with Flutter using **Material Design** principles. This UI is perfect for Android and iOS apps, with a clean look and easily customizable elements.

## ✨ Features

* App logo & title with custom fonts (Lato family)
* Welcome text & short description
* Email & password fields with icons and rounded borders
* Password field with visibility toggle icon (UI only)
* "Forgot Password" link with underline styling
* Styled **Log In** button
* Sign-up prompt for new users
* Responsive layout using `SafeArea` and padding

## 🛠️ Technologies Used

* **Flutter** (Dart)
* **MaterialApp** & **Scaffold** for app structure
* **SafeArea** for proper spacing
* **Custom Fonts** for branding
* **BoxDecoration** for UI styling

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/flutter-login-screen.git
   ```
2. Navigate to the project folder:

   ```bash
   cd flutter-login-screen
   ```
3. Install dependencies:

   ```bash
   flutter pub get
   ```
4. Run the app:

   ```bash
   flutter run
   ```
